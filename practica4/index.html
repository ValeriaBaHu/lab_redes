- Resumen -

En esta práctica se utilizan diversos sensores conectados a un ESP para recopilar datos en tiempo real. Posteriormente, estos datos se procesan y se visualizan a través de gráficas interactivas utilizando la plataforma ThingSpeak, la cual permite almacenar y analizar la información de manera eficiente.

Además, para facilitar el acceso a los datos y su visualización, se desarrolló una página web con la ayuda de Replit, una plataforma en línea que permite la programación y despliegue de aplicaciones web de forma sencilla. En esta página, los usuarios pueden consultar las gráficas correspondientes a cada sensor, lo que facilita el monitoreo y análisis de las mediciones obtenidas.

- Introducción -

En la actualidad, el uso de sensores y la conectividad a la nube juegan un papel fundamental en el desarrollo de aplicaciones de monitoreo y análisis de datos en tiempo real. Gracias a plataformas como ThingSpeak, es posible almacenar, procesar y visualizar la información proveniente de distintos sensores de manera eficiente.

En esta práctica, se integran varios sensores con un ESP (un microcontrolador con conectividad WiFi) para recopilar datos y enviarlos a ThingSpeak, donde se generan gráficas interactivas que facilitan su interpretación. Además, se desarrolló una página web utilizando Replit, permitiendo a los usuarios acceder a las visualizaciones de manera sencilla y en cualquier momento.

- Desarrollo -

Para la implementación del proyecto, se conectaron al ESP32 cuatro sensores: un botón (digital), un potenciómetro (analógico), un DHT22 (temperatura y humedad) y un PIR (movimiento). Se programó el ESP32 en Arduino IDE para leer los datos de estos sensores y enviarlos a un servidor web mediante WiFi.

Simulación

Para validar el funcionamiento del circuito antes de su construcción física, se realizó una simulación utilizando Wokwi y el entorno de desarrollo de Arduino IDE. Wokwi es una plataforma de simulación en línea que permite emular el comportamiento de microcontroladores como el NodeMCU (ESP8266), facilitando la prueba de código y conexiones sin necesidad de hardware físico.

El Arduino IDE se utilizó para escribir y compilar el código antes de cargarlo en la simulación de Wokwi. Esto permitió identificar y corregir posibles errores en la programación antes de implementarla en el circuito real. Gracias a esta etapa de simulación, se optimizó el diseño y se garantizó que la lógica de control funcionara correctamente, minimizando riesgos en la fase de construcción.

- Conclusiones -

En conclusión, la integración de múltiples sensores con el ESP32 y su conexión a un servidor web permite un monitoreo eficiente y en tiempo real de diversas variables sin depender de plataformas externas. La combinación de sensores digitales, analógicos e inteligentes demuestra la versatilidad del ESP32 para aplicaciones en el Internet de las Cosas (IoT).
