Dashboard PHP

Karen Itzel Najera De Gante y Valeria Barroso Huitrón
Ingeniería mecatronica
26/02/2025
Arduino Electrónica

- Resumen -

En esta práctica, se combinan diversos sensores (digital, analógico e inteligente) en un solo proyecto utilizando el ESP32. Se capturan simultáneamente los datos de un botón (sensor digital), un potenciómetro (sensor analógico), un DHT22 (sensor de temperatura y humedad) y un sensor PIR (detección de movimiento), enviándolos a una aplicación web basada en PHP. De este modo, es posible visualizar en un panel de control (dashboard) la variación de los valores en tiempo real, aprovechando la conectividad WiFi del ESP32.

- Introducción -

Los proyectos de Internet de las Cosas (IoT) suelen requerir la supervisión de múltiples variables al mismo tiempo y la visualización de su comportamiento en tiempo real. Gracias a su conectividad WiFi y a la gran cantidad de pines de entrada/salida, el ESP32 se presenta como una opción ideal para integrar distintos sensores y enviar la información a un servidor remoto.

En esta práctica, se explora la conexión simultánea de sensores digitales (botón y PIR), analógicos (potenciómetro) e inteligentes (DHT22) con un ESP32. Además, se configura un servidor web con un script en PHP para recibir y desplegar los datos de los sensores en un dashboard, permitiendo el monitoreo remoto en tiempo real. Esto facilita la personalización de la visualización de la información sin depender de plataformas externas.

- Desarrollo -

Para la implementación del proyecto, se conectaron al ESP32 cuatro sensores: un botón (digital), un potenciómetro (analógico), un DHT22 (temperatura y humedad) y un PIR (movimiento). Se programó el ESP32 en Arduino IDE para leer los datos de estos sensores y enviarlos a un servidor web mediante WiFi.

Simulación

Para validar el funcionamiento del circuito antes de su construcción física, se realizó una simulación utilizando Wokwi y el entorno de desarrollo de Arduino IDE. Wokwi es una plataforma de simulación en línea que permite emular el comportamiento de microcontroladores como el NodeMCU (ESP8266), facilitando la prueba de código y conexiones sin necesidad de hardware físico.

El Arduino IDE se utilizó para escribir y compilar el código antes de cargarlo en la simulación de Wokwi. Esto permitió identificar y corregir posibles errores en la programación antes de implementarla en el circuito real. Gracias a esta etapa de simulación, se optimizó el diseño y se garantizó que la lógica de control funcionara correctamente, minimizando riesgos en la fase de construcción.

- Conclusiones -

En conclusión, la integración de múltiples sensores con el ESP32 y su conexión a un servidor web permite un monitoreo eficiente y en tiempo real de diversas variables sin depender de plataformas externas. La combinación de sensores digitales, analógicos e inteligentes demuestra la versatilidad del ESP32 para aplicaciones en el Internet de las Cosas (IoT).
